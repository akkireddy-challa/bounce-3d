# Bitmagic

This is a Bitmagic game project.

**Read `AGENTS.md` at the project root before editing anything here.** It describes this engine
and this version of the GDK, `bitmagic upgrade` keeps it current, and it outranks anything you
remember about Bitmagic. Your own copy of the skills it names is in `.kiro/skills/`.

Two things it will tell you that are worth having before you have read it:

- **Start `bitmagic dev` in the background and leave it running**, before you build anything. It
  serves the game and the editor so the person you are building for can watch and steer.
- **Run `bitmagic reload` when you finish a turn**, so their browser shows the finished work
  rather than a frame from the middle of it. It exits 0 and does nothing when no dev server is up.
