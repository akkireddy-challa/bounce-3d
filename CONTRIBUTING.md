# Contributing to Bounce 3D 🔴

Thank you for your interest in contributing to **Bounce 3D**! 

Whether you are designing new obstacle levels, tweaking Rapier 3D physics restitution, crafting retro chiptune sound effects, or refining mobile touch ergonomics, we welcome your contributions.

---

## 🚀 Quickstart for Builders

1. **Fork & Clone**:
   ```zsh
   git clone https://github.com/akkireddy-challa/bounce-3d.git
   cd bounce-3d
   ```
2. **Install the Bitmagic Engine CLI**:
   ```zsh
   npm install -g @bitmagic/cli
   ```
3. **Launch the Live Scene Editor**:
   ```zsh
   bitmagic dev
   ```
   Open `http://localhost:3011` to inspect real-time 3D hot-reloads.

---

## 🎨 Design Principles
- **Nostalgia First**: Stay true to the original Nokia Bounce spirit—red bouncing ball, golden hoop rings, bouncy rubber trampolines, and red spike hazards.
- **Strict Mobile Parity**: Every level must be fully beatable with both desktop keyboards and smartphone touchscreens.
- **60 FPS Target**: Keep geometries clean and low-poly to ensure buttery-smooth performance across mobile GPUs.
